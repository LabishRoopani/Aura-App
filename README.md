## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/aura-app.git
```

Go to project directory:

```bash
cd aura-app
```

Install dependencies:

```bash
flutter pub get
```

Run the app:

```bash
flutter run
```
