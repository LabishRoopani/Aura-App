## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/aura-app.git
```

Navigate to the project:

```bash
cd aura-app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
